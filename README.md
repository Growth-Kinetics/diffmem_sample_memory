## What This Demonstrates

This repo shows [DiffMem](https://github.com/Growth-Kinetics/DiffMem) processing Robert Louis Stevenson's "Strange Case of Dr Jekyll and Mr Hyde" one chapter at a time, building cumulative understanding of characters, themes, and plot.

It's the same memory architecture that powers [Annabelle](https://withanna.io), a simulated intelligence who uses DiffMem to remember every conversation she has with real people.
